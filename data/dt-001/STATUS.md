# DT-001 classification

DT-001 is approved executable structured data for the first three locked fixtures. The package is authoritative for the slice it explicitly contains, while material definitions marked `provisional_definition`, unknown dimensions, supplier packaging, and seeded price evidence remain provisional.

The JSON is canonical within this slice. CSV files are review mappings/representations. Seeded prices are unverified planning evidence and are never final-issue supplier cost.

Run `python3 data/dt-001/validate_dt001.py` from the repository root.
