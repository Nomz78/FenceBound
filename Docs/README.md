# FenceBound documentation

See the repository-level [`SOURCE_OF_TRUTH.md`](../SOURCE_OF_TRUTH.md) for authority order and classifications.

- The Edition 1.0 Markdown/DOCX pair in this directory is the frozen canonical base.
- `authoritative/` contains approved integrated governance supplements.
- `status/` contains factual implementation records.
- `planning/` contains provisional punchlists and budgets.
- `reference/` contains supporting system/specification documents.
- `execution/` preserves execution prompts and procedures.
- `research/` contains evidence, never silent product or pricing authority.

The completed NCDOT Division connector handoff in `execution/` is retained for
transfer history and does not define a current active track.
