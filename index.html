FenceboundCAD Development Index

Local documentation authority · v5.4.0 · Updated 3 September 2026

Purpose

Drawing-driven fence layout, BOM generation, cost-basis estimating, quick-reference totals, and proposal output. Sold as a one-time perpetual licence: offline, no accounts, no subscription.

Current Status

v5.4.0 shipped and pushed. CSV price import, company profile, and full backup/restore are live. Estimate output is fully unbranded from Far-Out. Takeoff defects D1–D5 are specified with owner rulings but not yet implemented.

Open — Takeoff Defects

  • D1 Post tallies disagree: calcAutoMaterials() recomputes posts independently of getStats(). Fix first — likely upstream of D3 and D4.
  • D2 Linear materials and labour are not net of gate openings. Gates already bill separately via LABOR.gate, so per-LF across an opening double-bills.
  • D3 Post caps are unconditional; a barb arm replaces the cap.
  • D4 No post type receives a correct length. Gate posts inherit the run’s length and a flat 2 bags of concrete.
  • D5 Terminal counts do not reconcile across posts, bars, and bands.

Open — Product Decisions

  • Flexible rate models (D6 + field labour rates). The tool only accepts crew-rate + per-LF costing. Contractors quote in several styles — $/LF sell price, material as a multiple of labour, per-panel, per-section. Entering a sell price as cost currently reports 0.0% margin. Standout feature; treat as one problem, not two.
  • Gate pricing by fence material. LABOR.gate charges by gate type only, so a chain link walk gate and an ornamental one bill identically. Needs field data per material.
  • D7 “6 plus 1” is not a first-class concept; the user assembles it from separate flags.
  • Dual depth. Real depth drives material cost; spec depth (36" to a GC) belongs on submittals. The tool holds one number.
  • JSON price import silently clears provenance and overwrites the rate card without confirming, unlike the manual save.
  • A pale user-chosen accent can render branded PDF text nearly invisible.

Completed / Locked

  • Automated regression runner — 69 Playwright tests, 12-route persistence matrix, v5.4 port suite
  • Chain link field specification ratified into repository authority
  • 168 LF reference job locked as the D1–D5 regression fixture
  • CSV price-list import with column mapping and duplicate resolution
  • Company profile — branding, terms, deposit, validity, accent
  • Full backup / restore with staleness warning
  • Seeded costs labelled as placeholders
  • Phase One baseline stabilised; canonical pricing schema v2 accepted
  • 100-foot benchmark completed for every fence type

Dependencies

Field rate card and per-material gate labour data (owner-supplied). Distributor pricing is no longer a product blocker — customers load their own costs via CSV import; it remains a Far-Out Fencing bidding concern only. FenceScraper is a separate product and not a dependency of this tool.
