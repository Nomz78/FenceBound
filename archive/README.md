# Historical HTML archive

`index.html` is the canonical, editable FenceboundCAD runtime. The files in this
directory are historical or forensic artifacts retained for provenance; they
are not current application entry points.

| File | Classification |
| --- | --- |
| `FenceboundCAD v5.3.1.html` | Historical CAD predecessor |
| `FenceboundCAD v5.3.4-embedded-project-index.html` | Frozen forensic prototype; never edit or release |
| `FenceboundRateCard v2.1.html` | Historical Rate Card predecessor |
| `FenceboundRateCard-v5.3.2-embedded-project-index.html` | Historical embedded Rate Card artifact |
| `FenceScraper v2 4.html` | Historical FenceScraper predecessor |

FenceScraper v3 remains active at repository root because it depends on sibling
JavaScript files there. Archiving historical HTML does not change accepted
runtime behavior or authorize modification of frozen artifacts.
