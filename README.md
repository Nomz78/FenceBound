# FenceBound
FenceBound is a contractor-focused CAD and estimating platform built for the fencing industry. It transforms drawings into layouts, material takeoffs, pricing, proposals, and installation documents, reducing repetitive work while improving estimate accuracy, speed, and consistency.

## FenceScraper v3.0+ Deployment Contract

FenceScraper v3.0 and later are multi-file applications. `FenceScraper-v3.0-Validated-Market-Rate-Mapping.html` requires `fencescraper-discovery-pure.js` as a sibling file.

The HTML must not be copied, archived, deployed, or distributed alone. Repository moves and release packages must preserve relative paths. A future build/export process may generate a standalone bundled artifact, but the canonical development source remains modular.
